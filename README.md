# ⛽ Petrol Ofisi Otomasyon Sistemi

Petrol istasyonu operasyonlarının dijital ortamda yönetilmesini amaçlayan masaüstü otomasyon uygulamasıdır.

Bu proje, üniversite eğitimi kapsamında geliştirilmiş bir öğrenci projesidir. Temel amaç; petrol istasyonlarında gerçekleştirilebilecek çeşitli işlemlerin bilgisayar ortamında daha düzenli ve kolay şekilde yönetilmesini sağlamaktır.

## 🚀 Proje Özellikleri

* ⛽ Petrol istasyonu işlemlerinin yönetimi
* 👤 Kullanıcı ve müşteri işlemleri
* 📦 Ürün ve stok takibi
* 💰 Satış işlemleri
* 🗄️ Veritabanı işlemleri
* ✏️ Kayıt ekleme, güncelleme ve silme
* 🔎 Kayıt görüntüleme ve arama
* 🖥️ Masaüstü kullanıcı arayüzü

## 🛠️ Kullanılan Teknolojiler

* **C#**
* **.NET**
* **SQL**
* **Visual Studio**
* **Git & GitHub**

## 🎯 Projenin Amacı

Proje kapsamında bir petrol istasyonunda gerçekleştirilebilecek temel işlemlerin bilgisayar ortamında yönetilmesi ve verilerin düzenli şekilde saklanması hedeflenmiştir.

Uygulama geliştirilirken özellikle;

* Nesne yönelimli programlama,
* Veritabanı işlemleri,
* CRUD işlemleri,
* Masaüstü uygulama geliştirme,
* Kullanıcı arayüzü tasarımı

konularında pratik yapılmıştır.

## 🖥️ Uygulama

Uygulama **Visual Studio** kullanılarak geliştirilmiştir.

Projeyi çalıştırmak için:

```bash
git clone https://github.com/MustafaTasbasi/petrolOfisi.git
```

Ardından `petrolOfisi.sln` dosyası Visual Studio ile açılarak proje çalıştırılabilir.
